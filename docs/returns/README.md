# Returns & exchanges policy (Little Windmill)

- `refund-policy-new.html` – new Refunds & Returns policy, ready to paste into Shopify.
- `refund-policy-original-backup.html` – the live policy as at 12 Oct 2026 (last updated 30 Apr 2026), kept so it can be restored.

## Key rules
- Faulty / damaged / not as described: Australian Consumer Law applies to ALL items (including sale). Little Windmill pays return postage.
- Change of mind: customer pays return postage; for exchanges also pays postage to send the replacement. 30 days online / 7 days in-store (unchanged from the previous policy).
- Sale, reduced and FINAL SALE items: no change-of-mind returns or exchanges. This doesn't affect faulty-item rights.

## To publish

Wording is based on law-firm commentary on ACCC guidance, not legal advice. Have it checked before relying on it.
